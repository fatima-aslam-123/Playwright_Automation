# Playwright Testing Skill

## Rules
- Prefer stable locators
- Avoid hardcoded waits
- Use async/await properly
- Reuse helper functions

## Test Structure
- Arrange
- Act
- Assert

## Common Validations
- Element visibility
- API response validation
- Network waits
- Error handling

## Bug Reporting
Include:
- Steps
- Expected result
- Actual result
- Screenshots
